Este é o site institucional da sua empresa de Tecnologia e Automação (**LM Tech & Automação**), desenvolvido sob medida para apresentação corporativa e prospecção de clientes locais.

---

## 🚀 Como Publicar no GitHub Pages (Gratuito)

Você pode hospedar este site gratuitamente de 2 formas:

### Opção 1: Como seu Portfólio Principal (`lucasgabrielom.github.io`)

1. Abra o terminal na pasta deste projeto:
   ```bash
   cd C:\Users\Usuário\.gemini\antigravity\scratch\agencia-tech-site
   ```
2. Inicialize o repositório e faça o push para o GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: site oficial LM Tech & Automação"
   gh repo create lucasgabrielom.github.io --public --source=. --push
   ```
3. O site estará online em poucos minutos no endereço: **`https://lucasgabrielom.github.io`**!

---

### Opção 2: Em um Repositório Próprio (ex: `agencia-tech-site`)

1. Crie o repositório usando o GitHub CLI (`gh`):
   ```bash
   gh repo create agencia-tech-site --public --source=. --push
   ```
2. Acesse o repositório no GitHub -> **Settings** -> **Pages**.
3. Em **Source**, selecione a branch `main` e a pasta `/ (root)`. Clique em **Save**.
4. Seu site ficará online em: **`https://lucasgabrielom.github.io/agencia-tech-site/`**!
